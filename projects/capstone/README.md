# Capstone Project — Final Weeks (23–24)

## Goal
Build a complete site that demonstrates:
- Strong authoring workflows (pages, media, metadata)
- Reusable, accessible front-end blocks (Gutenberg)
- Performance and documentation quality
- Clean Git history and PR process

## Deliverables
- Live local WordPress site (screenshots and short screen recording)
- `wp-content/plugins/aem-blocks/` plugin or custom theme with multiple blocks
- Authoring Guide (markdown) describing how to use your blocks
- Performance report (Lighthouse or similar) with at least 3 improvements
- Pull Request with clear description and checklist

## Grading (Professor Mode)
- Functionality — 35 pts
- Authoring experience — 20 pts
- Front-end quality — 20 pts
- Accessibility and performance — 15 pts
- Documentation — 10 pts
**Total 100 → Letter Grade** (see scale in weekly rubrics)
