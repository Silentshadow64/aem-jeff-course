# Professor Mode — Grading and Feedback

For each **Ready for Grading** submission:
1. Open the Pull Request and review changes line-by-line.
2. Verify quiz answers and auto-grade multiple-choice (10 pts).
3. Evaluate the exercise (20 pts) and project milestone (70 pts) with the rubric.
4. Record numeric and letter grade in `grading/gradebook.xlsx`.
5. Leave actionable feedback:
   - What worked (specific)
   - What to improve (specific)
   - One concrete next step

**Letter scale (for all weeks and capstone):**
A = 93–100, A− = 90–92, B+ = 87–89, B = 83–86, B− = 80–82,
C+ = 77–79, C = 73–76, C− = 70–72, D = 60–69, F = 0–59.
