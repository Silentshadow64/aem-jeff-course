# AEM Learning Program (No SDK) — WordPress + GitHub

This repository is your workspace for a **6-month (24-week) course** to gain proficiency as:
- **AEM Author** (simulated via WordPress + Gutenberg), and
- **AEM Front-End/UI Developer** (Gutenberg custom blocks and component patterns).

You do **not** need Adobe AEM or the AEM SDK. All labs run locally with **LocalWP** and **GitHub**.

## How this repo is organized
- `setup/` — step-by-step environment guides for **Windows** and **macOS**.
- `week01` ... `week24/` — weekly modules with lessons, quizzes, exercises, projects.
- `projects/capstone/` — final capstone briefs and rubrics.
- `.github/ISSUE_TEMPLATE/` — templates to request TA help or submit for grading.
- `grading/gradebook.xlsx` — a gradebook you can open locally to track progress for **Jeff**, **Mattie**, and **Melanie**.

## Weekly workflow
1. **Create a new branch** for your week (examples in each `submission.md`).
2. Complete the **quiz**, **exercise**, and **project milestone** in the week folder.
3. Open a **Pull Request** from your branch to `main`.
   - Use the **"Request TA Help"** issue template any time during the week.
   - Use the **"Ready for Grading"** issue template when you finish the week.
4. TA feedback will appear as PR comments, and Professor grading will be recorded in `grading/gradebook.xlsx`.
