# Week 13 — Grading Rubric (Professor Mode)

**Total: 100 points → Letter Grade**

- Quiz (auto) — 10 pts
- Exercise — 20 pts
  - Completeness (10)
  - Clarity and screenshots (5)
  - Accuracy (5)
- Project Milestone — 70 pts
  - Functionality (30)
  - Author experience (15)
  - Front-end quality (15)
  - Accessibility/performance (10)

**Letter scale:**
- A = 93–100
- A− = 90–92
- B+ = 87–89
- B = 83–86
- B− = 80–82
- C+ = 77–79
- C = 73–76
- C− = 70–72
- D = 60–69
- F = 0–59
