# Week 18 — Submission Instructions

You can use **GitHub Desktop** or **Command Line**. Choose **one** method below.

## Method A — GitHub Desktop (Windows/macOS)
1. Open **GitHub Desktop**.
2. Click **Current branch → New Branch**.
3. Name your branch exactly like: `jeff/week-18` or `mattie/week-18` or `melanie/week-18`.
4. Click **Create Branch**.
5. Make changes in this `week18/` folder and save.
6. In GitHub Desktop, write a summary like: `Complete Week 18 quiz, exercise, project milestone`.
7. Click **Commit to your-branch-name**.
8. Click **Push origin**.
9. Click **Create Pull Request**.
10. In the browser, verify the title: `Week 18 — <Your Name>` and submit.

## Method B — Command Line (Windows PowerShell or macOS Terminal)
```bash
git checkout -b <yourname>/week-18
git add .
git commit -m "Complete Week 18 quiz, exercise, project milestone"
git push -u origin <yourname>/week-18
```
Then open GitHub in your browser. Click **Compare & pull request** and submit.
