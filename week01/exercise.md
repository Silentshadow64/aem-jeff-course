# Week 01 — Exercise (Author + Front-End)

**Theme:** Setup • WordPress + GitHub Foundations  
*Goal:* Practice the separation of content (authoring) and presentation (front-end) by completing concrete tasks that parallel AEM concepts.

## 🧩 Authoring Tasks (complete all)

1. **Create a Page — About Us**
   - In WP Admin → Pages → Add New.
   - Add three blocks: **Heading**, **Paragraph**, and **Image**.
   - Add **ALT text** to the image and set a **Featured Image**.

2. **Create taxonomy**
   - In **Posts → Categories**, add two categories: *Company*, *Culture*.
   - In **Posts → Tags**, add three tags: *team*, *history*, *mission*.
   - Assign them to an existing or sample post.

3. **Publish and verify**
   - Click **Publish → Publish** on both the About Us page and the post.
   - Visit each public URL to confirm they render correctly.

**Why this matters for AEM:**  
Pages ⇢ AEM Sites Templates + Components  
Tags & Categories ⇢ AEM Taxonomy  
Publishing ⇢ AEM Author → Publish Replication
